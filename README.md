# Aharonov-Casher-Modulation
Aharonov-Casher modulation of split fluxonium circuit properties, including qubit energy spectrum, transition frequency, and probe-resonator / probe-target longitudinal coupling.

This is used to implement a charge-basis tomography protocol where the quantum states of a target qubit can be reconstructed through the measurements on a probe qubit. The full circuit can be described as probe-resonator(or tunable coupler)-target. In this project, the probe qubit is a split fluxonium (two CPB junctions shunted by a JJ array superinductor and a capacitor) and the target qubit is a transmon.

Charge-basis tomography protocol on superconducting qubits (four-junction flux qubit-resonator-transmon): https://arxiv.org/abs/2502.07748

Aharonov-Casher effect on split fluxonium circuit: https://journals.aps.org/prl/abstract/10.1103/PhysRevLett.116.107002
